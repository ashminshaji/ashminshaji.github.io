# Ashmin Shaji Portfolio

## Publish on GitHub Pages

1. Create a public GitHub repository named `ashminshaji.github.io`.
2. Upload `index.html` and `style.css` to the repository root.
3. Open Settings → Pages.
4. Choose Deploy from a branch → `main` → `/ (root)` → Save.
5. After GitHub publishes the site, the portfolio URL should be `https://ashminshaji.github.io/`.

No email address is included on the site.
